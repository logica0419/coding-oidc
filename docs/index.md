# OAuth / OIDC 自作入門

OAuth / OIDC の仕組みを手を動かして理解するワークショップの教材です。

OpenID Provider (OP) と Relying Party (RP) を自作し、認可コードフロー + PKCE を動かします。

## 対象者

- Web アプリケーションを開発した経験がある方
- OAuth / OIDC を使ったことはあるが仕組みを理解していない方
- プロトコルの中身に興味を持っている方

## 必要なもの・準備

- PC
- ハンズオン環境のセットアップ手順に従って下さい。(準備中)
